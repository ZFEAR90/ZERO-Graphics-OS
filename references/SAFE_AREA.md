Source: the user's 1920×1080 guide image supplied in this conversation. Coordinates are read from that image, not an official machine-readable specification.

- Visible lower-third assembly: top approximately 847 px; ticker is below it.
- Foreground bottom limit: 823 px, leaving a 24 px gap above the assembly.
- Channel bug: approximately x=100–244, y=38–135 px. Global top clearance defaults to 152 px so either flipped layout clears it.
- Symmetric foreground side margins: 79 px. The illustrated lower-third spans approximately x=79–1844.
- The supplied image does not show an independently measurable taller breaking-news variant. Both editable presets start at 847 px; the user can enter a higher exclusion for a taller strap.

Beta 2.5 preserves requested foreground widths and typography instead of uniformly scaling the composition. It moves groups into the protected area, avoiding both the TV logo and top-right Live reservation when flipped. A source that is taller than the available vertical span gets a shorter scrolling viewport; its content is not stretched. Bullet panels can shorten their visible height while retaining text size. The default account group is 90% of the original, independent of source aspect ratio, with a further 5% reduction on the TV-logo side; its own size setting can override the base size.

The lower-third tint and edge from Beta 2.4 remain. The earlier mint title-safe outline (top/bottom/sides) and orange lower guide are restored, with separate TV/Live corner outlines. Guide DOM overlays are absent from PNG/WebM output. Painted lower-third pixels are checked over 151 entrance frames, separately from raw crop/selection rectangles, which include historical blank margins.

The safety band is finite: the original tall source plus an account header cannot both fit at their full height between 152 and 823 px. Shortening the viewing window avoids reducing widths, text and account graphics. Turning protection off restores the unrestricted height. Explicit extreme sizes warn instead of triggering an automatic whole-composition scale. Whole-composition offsets and per-group movement clamp at the on-air limits, with an undoable edit for each drag.

Beta 2.7 uses position-dependent top limits: an element/group whose destination bounds lie between the reserved corner rectangles can rise to the title-safe top at scene y=34 (68 px). Elements intersecting either corner remain below the 152 px clearance. Horizontal motion is evaluated before the vertical clamp, so diagonal drags into the middle release the corner restriction in the same gesture. Larger solo rolls use the central header space; wide rolls that still intersect corner areas retain the corner limit.

Beta 2.7 also has an explicitly user-authorized exception for a single portrait (ratio 0.42–0.72) in **Large centered portrait** mode. Its roll alone may extend below y=847 and reach scene y=508 (1016 px); bullet/header groups still use the normal 823 px limit. The compact account header is centered above it, between the TV/Live reservations. The default roll height is 740 px with bullets, larger with bullets off, preserving media aspect ratio. The lower-third tint/edge is retained and labels the exception. Switching to Balanced, Beside, text-only, or non-portrait media removes this exception. Balanced and Beside preserve the complete media picture inside the usual protected area. Focused tests verify both flip directions, immediate policy changes and final saved settings.

Latest user refinement: the **Live** box now ends at the green top-safe line, y=68 px (scene y=34), instead of sharing the taller TV-logo exclusion. The TV-logo side remains at y=152 px. A group outside the TV reservation can rise to y=68; horizontal destination bounds are checked before clamping the vertical move. The guide itself is shortened accordingly.

The user also extended the lower-third allowance to large post photos/videos in general. **Allow large post photos/videos below lower third** defaults on and applies only to independently selected media; it gives the source a maximum bottom of 1016 px when needed. Bullet text/header still use the usual protected lower limit. It does not apply to text-only rolls, flattened screenshots or the original reference article. Disabling the checkbox restores normal source protection, including centered portraits. Balanced/Beside defaults still fit above the lower third, but their roll may be moved lower when the option is enabled. Single landscape posts retain balanced column widths; the extra space comes from height rather than squeezing the bullet column.

Final user correction in this update: **Respect safe area** is a Main On/Off button, defaulting Off for the requested taller bullet/roll composition. Off leaves guides visible but permits overlaps and unrestricted movement. Initial automatic TV-side placement remains. On enables strict fitting and disables the optional media exception; the existing media checkbox may then be used to allow only the roll below the lower third. Thus the protected limits described above apply when protection is enabled. Imported bullets keep their requested full height with protection off (the focused portrait uses a 640 px bullet panel), rather than always shortening at the lower third. The account group default is now 85%, plus TV-side compensation; the focused portrait group uses an additional 0.78 factor. A single selected photo uses contain rendering in a fixed region while its caption scrolls independently.
