AEP inspection for V0.7 Test Beta 1

The supplied ali.aep is a 3,674,314-byte RIFX/Egg! project. A bounded big-endian chunk traversal found 457 lhd3 records and 151 fnam records across the entire project, plus transform/property containers (tdgp/tdb4), shape/stroke and effect records. These counts cover the project, not just the active roll.

Readable names include WEB_ROLL_1, X_ROLL_1, X_ROLL_2, ROLL_MASK, SOLID_MASK, IMAGE_MASK, WHITE_BACK_MASK, STROKE-1, STROKE-2, TEXT_BACK, TITLE_BACK. Effect identifiers include ADBE Geometry2, ADBE Fill, ADBE Drop Shadow and slider/color/layer controls. These establish structural evidence; they do not establish decoded layer timing or Bezier interpolation.

The browser beta keeps separate header, masked source, and bullet renderers. Enhanced Motion uses quintic ease-in/out with zero first and second derivatives at rest, preserving V0.7 event windows and nested construction. Reference Match keeps the prior easing treatment. The new header layout applies in both modes.

The full original video could not be transferred through the 32 MiB file tool. The embedded 960×540, 25fps, 71.48s proxy is retained separately. Representative enhanced entrance frames were inspected at 0, 0.32, 0.8, 1.2, 1.6, 2.12 and 4s. Native AE easing and a full-resolution matched-frame fidelity audit remain outstanding.
